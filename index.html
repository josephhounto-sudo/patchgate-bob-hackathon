The workflow

From patch to decision.

Three steps, one readable trail. The tool surfaces evidence; the reviewer makes the call.

±

Inspect the diff

Review prompts highlight additions matching a small set of explicit patterns. Deletions are called out for manual inspection.

⌁

Trace the change

For changed top-level Python functions, see direct calls found inside test functions, with file and line references.

✓

Record a decision

Mark each prompt Reviewed or Needs fix, then export a JSON review record tied to that exact diff.

Clear limits build trust

Evidence is a starting point.

PatchGate is a deterministic review aid. A direct name match does not prove the test executed the changed lines. No match does not prove a function is untested.

  • Only tracked text changes are scanned; untracked and binary files are outside scope.
  • Deletion-only changes may be missing from the function impact list and are flagged for manual review.
  • Pattern matches are prompts, never confirmed vulnerabilities. The export records decisions, not certified approval.
